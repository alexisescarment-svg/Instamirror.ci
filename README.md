# Instamirror

Site vitrine d'Instamirror (Abidjan) : le miroir lumineux au format post Instagram.

- `index.html` : le site complet (accueil, réalisations, fiche produit, configurateur, FAQ).
- `configurateur.html` : le configurateur seul, à intégrer dans une autre page (Framer, etc.).
- `framer-embed.html` : le code à coller dans un bloc Embed de Framer.
- `merci.html` : page affichée après l'envoi du formulaire sans JavaScript.
- `img/` : photos et logos.

Hébergement : Netlify (site statique, pas de build). Le formulaire « commande-miroir » utilise Netlify Forms.
